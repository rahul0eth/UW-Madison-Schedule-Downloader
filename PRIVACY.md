# Privacy Policy

**Extension:** UW Madison Schedule to Calendar
**Last updated:** August 23, 2026

## Summary

This extension does not collect, store, transmit, or sell any user data. Everything it does
happens locally in your browser.

## What the extension does

When you click the extension's "Download Schedule" button on the UW–Madison course schedule
page, it reads the schedule information already present on that page (your courses, meeting
times, locations, and final exam dates), converts it into a calendar file in the standard
`.ics` format, and saves that file to your computer through your browser's normal download
mechanism.

## Data collection

**None.** Specifically:

- No data is transmitted to the developer or to any third party.
- No data is sent to any server. The extension makes no network requests of any kind.
- No data is stored by the extension after the download completes.
- No analytics, telemetry, tracking, or advertising code is included.
- No cookies are read or written.
- No browsing history is accessed.

The schedule data the extension reads never leaves your device. It is read from the page you
are already viewing and written directly into a file you download.

## Permissions

- **`activeTab`** — lets the extension read the schedule from the tab you are actively viewing,
  and only at the moment you click the extension. It grants no access to other tabs.
- **Host access to `mumaaenroll.services.wisc.edu/courses-schedule`** — the extension's content
  script runs only on the UW–Madison course schedule page. It does not run on any other website.

## Remote code

The extension executes no remote code. All code is contained in the published extension package.

If this policy changes, the updated version will be posted at this URL and the "Last updated"
